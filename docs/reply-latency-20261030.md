## 改动

- 通过自有插件的可撤销调度适配，正常停止后继续执行当前生成器的收尾，让原生历史提交及 handler/agent 结束记录先于整条链路结束。不删除、改写历史错误，不把真实提供方异常改成成功；卸载时仅恢复本插件仍持有的绑定。没有修改宿主源码文件。
- MaiBot Planner 已选定的回复沿用现有目标与上下文完成，普通新消息继续登记，不再撤销这次已开始的生成。明确唤醒、权限/人格变化和上下文清空仍可撤销。完成这次回复后解除冻结，后续真实等待仍可被新消息续接，避免持续占住房间。
- 固定 Planner 回复工具的说明，将候选表达 ID 保留在本轮数据与既有校验中，避免候选变化不断改变工具前缀。没有切换模型、缩减召回范围或降低已有检索预算。
- 在原生回复进入历史和发送之前，剥离已经观察到的内部上下文回显尾部；保留前面的正常回复和代码块中的示例。整段仅有内部资料时不发送资料。补充正文边界及群友约局的参与身份规则。
