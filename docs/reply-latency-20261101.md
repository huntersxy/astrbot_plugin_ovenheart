# 2026-11-01 私聊短句回复延迟

线上 `aiocqhttp` 私聊「菲比啾比」的链路记录显示：入站到规划器提交 `reply` 约 13 秒，原生正文模型从提交到完成约 20 秒，梗百科未知词预查最多再占 2 秒；完整首条文字发送约 34.6 秒。原生模型是主要等待点，平台发送本身只在正文完成后增加了很短的收尾时间。

本次调整让 aiocqhttp 私聊直接回复恢复原生流式，首段文字可以在模型首包后尽早可见，同时保留规划器的最终投递回执。群聊仍保持缓冲，以便先完成目标引用、真实 @ 和过期回复校验；QQ 官方机器人也保持原有非流式边界。

短私聊不再为可选表情额外调用图库工具；主动候选已经存在时仍可由 `reply.attach_emoji` 选用，较长私聊和群聊保留原有表情工具。
