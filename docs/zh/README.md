# 人格工坊使用指南

## 安装和入口

需要 AstrBot `>=4.29.1,<5`。在 Panel 安装本地插件 ZIP 后启用，页面从插件 View 入口「人格工坊」打开。也可复制插件文件夹至宿主 `data/plugins/astrbot_plugin_persona` 并重载。

该页面复用 AstrBot 登录鉴权、原生 Bridge 与明暗主题，不需要 `pnpm`、前端构建或额外服务。直接双击 HTML 会显示需要从 Panel 打开的提示。

本版本是新插件，没有旧入口迁移。四个页面分别为：

| 入口 | 功能 |
| --- | --- |
| 人格底稿 | 人工补充身份、表达基调、行为准则；会话级学习与应用开关；预览追加的提示词 |
| 学习库 | 按类别与状态查看结果、检查证据、编辑、批准、拒绝、停用 |
| 学习记录 | 批次状态、失败原因、记忆联动情况、恢复修改前的版本 |
| 学习设置 | 全局开关、生效方式、证据门槛、学习对象、模型、节奏与数据保留 |

## 首次设置

先在 AstrBot 配置你的核心人格，再在允许的会话中发几条普通文字消息。插件按当前宿主实际生效的人格与完整会话来源分别保存素材，切换人格会看到独立的学习空间。群聊优先显示群名，私聊显示对方名字；群名不可用时显示群号。

建议先保留「先审核后生效」，也可按需要切换为「高置信度自动生效」。这是**配置项**：自动模式只影响未来的新候选，不重新激活已拒绝或停用的旧条目。置信度来自模型评估，不是统计保证；默认还要求至少两条不同原始消息作为证据。

「只向这些用户学习」每行一个用户 ID，留空为所有允许会话的真人。「允许学习与应用的会话」填写完整 `unified_msg_origin`，可通过 AstrBot `/sid` 获取，留空为所有已启用会话。AstrBot 自身的白名单、插件集、会话与插件开关仍生效。

## 批次和模型

默认积累 12 条素材触发自动学习，每批最多 30 条，同一会话的尝试间隔至少 600 秒；全插件同时最多一个学习模型请求。手动学习可绕过自动素材门槛与冷却，但仍需要满足最少证据数。一次模型请求超时为 90 秒；记忆检索超时为 12 秒。

「学习模型 ID」留空时使用该会话当前模型，否则填写 AstrBot 已配置的提供商 ID。插件不会自行设置或保存 API Key。模型必须能够输出指定 JSON；无效 JSON、虚构证据或调用失败会显示具体修复方向并保留素材。空候选数组是有效结果，代表本批没有足够依据提炼习惯。

学习期间暂停、停用会话或修改底稿，迟到的学习结果不会覆盖新的设置。相同情境与内容的候选去重；不同措辞的候选可能仍需人工合并判断。本版本提供审核、编辑和停用，不声称语义级完全去重。

## 与记忆插件配合

启用 LivingMemory 的联动开关即可，无需填写端口、URL 或令牌。插件发现已启用且就绪的 LivingMemory 实例后，按它的权限、记忆作用域和人格过滤规则检索。默认最多取三条上下文，仅帮助理解素材，不能代替原始聊天证据。重载后尚未收到该会话的新事件时，该批只使用已保留的原始聊天素材。

这是可选联动；接口不兼容、未安装、未就绪、被停用、权限禁止或检索超时会在学习记录中解释，不中断独立学习。实际记忆检索可能更新 LivingMemory 的访问时间，并可能运行其原有旧作用域迁移。本插件不向 LivingMemory 写入额外记忆。

QQ 能力增强可同时启用，无需特殊适配。人格工坊只补充对话习惯，不自动调用它的管理或发送工具。

## 保留与恢复

默认原始素材保留 14 天，每个会话人格最多 300 条。定期清理在后台进行，素材满额时淘汰最旧消息。学习结果、证据摘录与修改快照不随原始素材过期而清除；原始素材清除按钮也不会删除证据摘录。

人格、条目编辑和审核前自动保存快照，最多 30 份。恢复将还原该快照的底稿与旧条目状态，把之后新增的条目停用；恢复操作本身也留快照，可以再次恢复。素材清除不可撤销，恢复快照不能恢复原始消息。

所有数据位于 AstrBot `data/plugin_data/astrbot_plugin_persona/persona.sqlite3`，与其他插件数据分离。备份时建议先停用本插件，完整备份插件数据目录，避免漏掉 SQLite 的 WAL 文件。
