# 聊天回想

固定对照 MaiBot `5c7637e6913c84d1c3d5e742fa9e95a7e70d3501` 的 `src/maisaka/memory/mid_term.py`。移植原摘要解析、线索归一、余弦评分、候选选择、摘要编号和内部参考格式，保留原中文摘要模板；文件和符号 AST 来源见 `vendor/maibot/mid_term_source.json`，可用 `scripts/port_midterm.py` 重现。原上下文对象由原生内部参考身份替代，不模拟平台消息。

结构化模式从已有持久上下文中选取已离开当前 Planner 短期窗口的真实人类发言；原生模式每十二条获准素材检查一次 AstrBot 自己的 PlatformMessageHistory，按当前原生会话创建时间截断，保留最近三十条作为原生 Planner 窗口。没有另建聊天全文库。积累十二条未压缩旧发言后后台压缩，每批原文最多16000字，同作用域每600秒最多尝试一次；机器人输出、命令与排除作者不用于压缩。私聊、群聊按真实会话和人格隔离。

原模板生成完整摘要与最多五条查询式召回线索。摘要通过原 SDK 写入当前会话的真实段落，保留每条原生来源、作者、摘录和时间；中期载荷与压缩进度留在该段落的 metadata 中。该段落同时可由普通检索找到，不做第二套记忆数据库。更正、遗忘和撤销继续使用同一 SDK 日志、有效性过滤与原生 Planner 工具；被遗忘的摘要不会通过中期召回继续出现，原压缩进度仍保留，避免立即重建被遗忘内容。

召回读取最近 `midterm_memory_limit` 条中期记录（默认10），使用最近十二条上下文、每条最多360字及总计2400字构造语义查询。按原余弦实现选择严格大于0.8的最佳线索，使用原内部参考格式提供给 Planner 和 Replyer；同一段落与通用检索结果去重。嵌入配置改变时跳过旧配置的线索，不将相同维度当成模型兼容。没有可用嵌入或线索嵌入失败时仍保存文字摘要供普通检索使用，不伪造中期语义匹配。

`midterm_memory_enabled` 控制应用与更新，写入额外受学习和真实来源权限控制。模型调用计入 `midterm_summary` 辅助用量；生成后复核配置、应用、学习和原生会话/上下文代次，清空会话后不提交旧任务。保留数控制当前中期候选集，早期真实段落仍按原长期记忆生命周期管理。

定向检查使用真实结构化上下文、AstrBot SQLite/PlatformMessageHistory、原 SDK 存储和原评分算法；模型与嵌入运输为受控响应。覆盖移出窗口后的摘要、原文来源、语义命中及拒绝、实际遗忘、压缩进度、原生历史复用、无嵌入文字保存和暂停学习。另核对发布包独立导入及模板包含。未运行全量回归，未做线上或真实模型质量验收。
