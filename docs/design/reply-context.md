# 群聊回复的目标与执行边界

0.57.1 在统一群聊记录之外，单独给本轮回复提供有界的 `reply_focus`：真实目标、同一成员此前的发言、机器人自己的近期发言。它们都来自当前会话，不作为系统指令，也不表示临近消息一定相关。机器人自己的身份由消息来源确定，不由昵称判断。焦点记录冻结后不受后续群消息修改，作为临时输入，不重复写入宿主会话。

直接唤醒的原生任务仍然存活时，自主参与先等待，不额外占用同群生成流程；新的直接唤醒仍走宿主流程。自主回复前再次核对任务、会话与消息状态。已有实际答复关系的目标留作背景，不能再次被自主选中。这里的“已答复”只表示已有机器人发言，不证明用户的多步任务已经完成。

可选习惯检索具有总等待上限；提供商取消缓慢时，也不能继续占着原生会话锁。超时跳过可选习惯，并在记录中明确说明。空模型结果单独记为“未生成回复”，不把它说成发送成功，也不自动重放可能已经执行的工具。诊断只记耗时、数量和状态，不保存模型内部推理。

## Oven Multi 可选联动

0.58.0 与 Oven Multi 1.54.0 通过运行时插件注册表互相发现，不互相导入代码。只有烤箱之心已就绪、启用应用且当前群聊通过宿主与人格应用开关时，Oven Multi 才跳过成员追踪、发言人提示、标签转 @ 和旧 Jev 注入路径；停用、卸载或会话禁用时恢复独立行为，原有配置值保留。

Jev 的密钥、模型和启用选项仍由 Oven Multi 管理。联动模式使用当前冻结的目标、同成员前文、自己的发言与媒体描述，不另建群聊历史；向外部判读服务发送前将成员身份替换为临时别名，不发送图片引用路径。返回的六维判读及建议是临时参考，不能改写明确任务、工具权限或回复目标。参与规划保留原有阈值与最终决定权。

规划器选择与判读相同目标时复用结果；选择其他消息时按实际目标重新判读。同一事件的缓存同时绑定配置签名、实例、会话及冻结内容；调用结束后再次核对所有权和会话，过期结果丢弃。单次可选调用总等待上限四秒，不重试，失败继续正常请求；诊断仅新增状态、耗时和复用标记。未安装 Oven Multi 或 Jev 未开启时，不增加外部判读请求。

## bili 压缩兼容验证

Oven Multi 1.54.1 在 SDK 请求层对没有原生会话 ID 的辅助调用使用 bili 官方透传标记，避免参与规划、习惯检索和后台学习被注入压缩工具或绑定匿名会话。正常回复仍由 AstrBot 携带真实 conversation ID，群聊记录及 `reply_focus` 不因代理压缩而被替换为摘要；原生会话重置和人格隔离规则保持有效。SDK 实例适配可卸载恢复，不修改 AstrBot 或 bili 源码。

本地测试将实际参与规划、冻结目标与自身图片描述送过真实 AstrBot SDK，核对辅助请求透传、主回复会话标识及持久化记录完整。Oven Multi 的可选真实代理测试还验证 bili 0.1.206 的压缩成块与后续重建，并处理纯压缩回执的有限续答。这里验证的是传输与上下文契约，未宣称真实模型的摘要质量或线上长聊效果。

## MaiBot 对照来源

0.57.2 同时登记机器人发出的图片，而不只抽取回复的文字。混发图片在发送钩子登记；meme_manager 单独发送和流式结束后发图的路径，通过可卸载的实例适配器在发送函数成功返回后登记。所选表情的描述来自该轮候选资料；其他混发图片必须匹配内容摘要，否则不套用那张表情的描述。可用时复用 QQ 增强插件的真实会话图片引用、配额和有效期，不伪造引用。没有现成描述的临时图片在文件清理前取好输入，再按已有图片描述配置异步处理；关闭图片描述时不增加模型请求。发送记录及其描述进入下一轮 `reply_focus.recent_self`，仍不作为学习原始证据。这里记录的是发送路径已返回，不额外宣称客户端已收到图片。

这与下列 MaiBot `reply.py` 中将实际 `MessageSequence` 交给发送服务并同步到会话历史的方式一致：机器人自己的媒体同样是聊天记录的一部分。

对照本机 MaiBot 提交 `5c7637e6913c84d1c3d5e742fa9e95a7e70d3501`：

- [maisaka_generator_base.py](https://github.com/Mai-with-u/MaiBot/blob/5c7637e6913c84d1c3d5e742fa9e95a7e70d3501/src/chat/replyer/maisaka_generator_base.py)：`_build_target_message_block`、`_build_final_user_message` 将回复目标、原文与本次要求独立交给回复器，区分机器人自己的发言。
- [reply.py](https://github.com/Mai-with-u/MaiBot/blob/5c7637e6913c84d1c3d5e742fa9e95a7e70d3501/src/maisaka/builtin_tool/reply.py)：`_find_recent_reply_to_target`、`reply_reference` 明确关联目标及已回复关系，生成失败保留可检查的结果。
- [planner_messages.py](https://github.com/Mai-with-u/MaiBot/blob/5c7637e6913c84d1c3d5e742fa9e95a7e70d3501/src/maisaka/context/planner_messages.py)：消息编号、时间、引用和自身发言具有独立的结构字段。
