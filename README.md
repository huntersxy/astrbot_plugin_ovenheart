# 烤箱之心 · OvenHeart

**从相处中学习表达，记住有来源的共同经历。**

AstrBot 人格学习、聊天规划与记忆插件。

[使用指南](docs/guide.md) · [开发指南](CONTRIBUTING.md) · [English](docs/en/README.md) · [问题反馈](https://github.com/huntersxy/astrbot_plugin_ovenheart/issues)
</div>

## 安装

需要 **AstrBot ≥ 4.29.1、< 5**，支持 QQ / OneBot v11（aiocqhttp）。先在 AstrBot 配置可用的聊天模型，再在插件管理中通过仓库链接安装：

```text
https://github.com/huntersxy/astrbot_plugin_ovenheart
```

打开插件卡片的 **人格工坊**。页面使用 AstrBot 的登录和权限，无需额外服务或端口。

## 开始使用

1. 在 **人格底稿** 填写表达基调和行为偏好，AstrBot 的人格设定继续生效。
2. 在 **设置 → 学习与生效** 选择学习对象和范围。默认积累至少 12 条合格素材后学习，生成的习惯需要在 **学习库** 审核后生效。
3. 在 **记忆 → 记忆设置** 配置文字嵌入提供商 ID；图片相似检索使用独立的多模态嵌入提供商 ID。提供商在 AstrBot 中创建。
4. 想让机器人主动参与群聊时，在 **设置 → 群聊参与** 先选择“仅观察”，确认时机后再开启自动参与。

想使用表情时，打开 **表情 → 上传与导入**，添加图片和用途描述，或导入现有 `meme_manager` 图库；再到 **选择与发送** 开启 Planner 表情动作。默认按描述选择，无需另配情感模型。

分段回复默认采用本地规则，无需另配模型。在 **设置 → 表达与检索** 可调整段数和发送间隔；模型语义断句为可选项，配置说明见[分段回复指南](docs/guide.md#分段回复)。

学习、规划、摘要和部分检索会调用已配置的模型服务。学习通过检索和提示词影响回复，不训练模型权重。

聊天规划会结合当前对象和语境，从已审核的表达中选择适合本轮的规则与原话片段，也可以不选。正文沿用这次选择，不再另取一批表达；当前输入命中的群内词汇仍单独提供释义。等待期间收到新消息时，会更新人物资料、回忆和表达候选，再决定回复谁。

## 功能

| 功能 | 管理入口 |
| --- | --- |
| 学习人格倾向、表达、词汇和行为习惯，查看原文证据并审核 | 学习库 |
| 持续规划回复、等待和结束，选择真实回复对象 | 设置 → 群聊参与 |
| 保存共同经历、人物事实和图片，按来源召回 | 记忆 |
| 查询、更正、遗忘和撤销记忆修改 | 聊天中的明确请求 / 记忆控制台 |
| 查看关系、时间线、图片和有效状态，导入导出记忆包 | 记忆控制台 |
| 从 LivingMemory 复制文本，保留来源与重复导入去重 | 记忆 → 导入与来源 |
| 公共表情图库、上传、meme_manager 素材导入与自动选择 | 表情 |
| 有依据地复核陈旧或相关记忆，确认建议与回滚 | 记忆 → 记忆检修 |
| 外观描述和参考图，帮助人格辨认自己的形象 | 自画像 |
| 本地或语义分段和回复节奏 | 设置 → 表达与检索 |

自主群聊参与和名字唤醒默认关闭，工具调用受 AstrBot 的会话、人格和权限限制。人格与表达习惯默认共用；群聊词汇始终按会话与人格隔离；记忆默认按会话隔离，可在记忆设置中关闭隔离，让同一人格跨会话共享。私聊记忆也会进入共享范围，不同人格仍分开。开关只控制召回范围：关闭后自动包含切换前积累的全部会话记忆，记录保留原始来源，开启后恢复当前会话范围。

引用消息会单独保留原作者和消息 ID，只作为理解回复的上下文。人物事实的证据来自本人正文，不会因为 B 引用了 A 的话就把 A 的经历记到 B 名下；只有引用、没有本人正文的消息不提取人物事实。

在 **表情 → 选择与发送** 调整主动推荐比例和最短间隔。默认每轮有 50% 概率提前向聊天模型提供候选，同一会话发表情后间隔 30 秒再主动推荐；模型根据语境选图，不额外调用选图模型。设为 0% 仅按明确请求使用，100% 每轮提供候选，实际发送仍看是否合适。用户明确索要表情不受主动间隔限制。

主动复核默认全插件每小时最多一轮、每轮最多检查两条记忆，复用现有修正日志。有更新原文支持且把握足够的更正才自动执行，其余在 **记忆 → 记忆检修 → 修正历史** 查看建议与依据、确认或回滚；不会仅因记录陈旧而删除。可在记忆设置中关闭或调整间隔，模型调用计入辅助用量。

在 **自画像** 选择当前人格的真实会话，填写外观描述，可上传静态 PNG、JPG 或 WebP 参考图（2 MB 以内）。普通文字对话只附上描述；处理来图且回复模型支持识图时，才附上参考图，不额外调用识图模型，也不替换 AstrBot 人格身份。
