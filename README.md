# 烤箱之心 · OvenHeart

**从相处中学习表达，记住有来源的共同经历。**

AstrBot 人格学习、聊天规划与记忆插件。

[使用指南](docs/guide.md) · [开发指南](CONTRIBUTING.md) · [English](docs/en/README.md) · [问题反馈](https://github.com/huntersxy/astrbot_plugin_ovenheart/issues)
</div>

## 安装

需要 **AstrBot ≥ 4.29.1、< 5**，支持 OneBot v11（aiocqhttp）以及 QQ 官方机器人（WebSocket / Webhook）。先在 AstrBot 配置可用的聊天模型，再在插件管理中通过仓库链接安装：

```text
https://github.com/huntersxy/astrbot_plugin_ovenheart
```

打开插件卡片的 **人格工坊**。页面使用 AstrBot 的登录和权限，无需额外服务或端口。

## 开始使用

1. 在 **人格底稿** 填写表达基调和行为偏好，AstrBot 的人格设定继续生效。
2. 在 **设置 → 学习与生效** 选择学习对象和范围。默认积累至少 12 条合格素材后学习，通过入库自检且达到置信度门槛的新习惯自动生效；存疑结果可在 **学习库** 审核。
3. 在 **记忆 → 记忆设置** 配置文字嵌入提供商 ID；图片相似检索使用独立的多模态嵌入提供商 ID。提供商在 AstrBot 中创建。
4. 自主群聊参与默认开启，可在 **设置 → 群聊参与** 调整频率，或切换为“仅观察”“关闭”。已有安装保留原设置。

工坊由后台自动学习，不再提供全局手动学习按钮。学习库、记忆、表情与记录默认展示全部来源，自画像默认列出全部人格；需要缩小范围时使用各页的局部筛选。导入、编辑和清理操作在对应内容或表单中确定目标，底稿预览可单独选择「示例会话」。

想使用表情时，打开 **表情 → 上传与导入**，添加图片和用途描述，或导入现有 `meme_manager` 图库；再到 **选择与发送** 开启 Planner 表情动作。默认按描述选择，无需另配情感模型。

分段回复默认采用本地规则，无需另配模型。在 **设置 → 表达与检索** 可调整段数和发送间隔；模型语义断句为可选项，配置说明见[分段回复指南](docs/guide.md#分段回复)。

学习、规划、摘要和部分检索会调用已配置的模型服务。学习通过检索和提示词影响回复，不训练模型权重。

在 **设置 → 模型分工** 分别选择 Planner、习惯学习、入库自检、表达情境筛选、记忆整理、人物提取、记忆复核、语义断句与表情视觉选择的模型。选项来自 AstrBot 已启用的聊天模型，内部环节留空时沿用当前会话模型；可选的表情视觉选择留空时使用宿主图片描述模型。最终回复的模型和生成设置始终由 AstrBot 当前会话决定。

支持按群名片、昵称或账号查找真实成员，并在同一条原生回复中 @ 指定成员或其他机器人、附上文字或指令。提及支持多位成员、流式与分段发送，遵循 AstrBot 工具权限；同名先确认，发送结果不代表另一个机器人已经执行成功。

QQ 官方机器人使用 OpenID，不提供 OneBot 的群成员列表接口。插件会自动隐藏需要成员列表核验的提及工具，已知发送者仍可正常 @；官方平台只能可靠引用当前入站消息，不会把旧消息 ID 强行当成官方引用。官方平台的单次回复最多分成 3 段，其他平台沿用原配置。

聊天规划会结合当前对象和语境，从已生效的表达中选择适合本轮的规则与原话片段，也可以不选。正文沿用这次选择，不再另取一批表达；当前输入命中的群内词汇仍单独提供释义。等待期间收到新消息时，会更新人物资料、回忆和表达候选，再决定回复谁。

规划与正文共用相处准则：按现有人格形成看法，衔接同一话题里已经说过的话，允许简短反应、接梗和不同意见；不为续聊固定追问。亲疏与态度变化以真实互动为依据，明确任务仍完整回应。

## 功能

| 功能 | 管理入口 |
| --- | --- |
| 学习人格倾向、表达、词汇和行为习惯，查看原文证据并审核 | 学习库 |
| 持续规划回复、等待和结束，选择真实回复对象 | 设置 → 群聊参与 |
| 保存共同经历、人物事实和图片，按来源召回 | 记忆 |
| 查询、更正、遗忘和撤销记忆修改 | 聊天中的明确请求 / 记忆控制台 |
| 查看关系、时间线、图片和有效状态，导入导出记忆包 | 记忆控制台 |
| 从 LivingMemory 复制文本，保留来源与重复导入去重 | 记忆 → 导入与来源 |
| 公共表情图库、上传、meme_manager 素材导入与自动选择 | 表情 |
| 有依据地复核陈旧或相关记忆，确认建议与回滚 | 记忆 → 记忆检修 |
| 外观描述和参考图，帮助人格辨认自己的形象 | 自画像 |
| 本地或语义分段和回复节奏 | 设置 → 表达与检索 |

自主群聊参与默认开启，名字唤醒默认关闭，工具调用受 AstrBot 的会话、人格和权限限制。人格与表达习惯默认共用；群聊词汇始终按会话与人格隔离；记忆默认按会话隔离，可在记忆设置中关闭隔离，让同一人格跨会话共享。私聊记忆也会进入共享范围，不同人格仍分开。开关只控制召回范围：关闭后自动包含切换前积累的全部会话记忆，记录保留原始来源，开启后恢复当前会话范围。

引用消息会单独保留原作者和消息 ID，只作为理解回复的上下文。人物事实的证据来自本人正文，不会因为 B 引用了 A 的话就把 A 的经历记到 B 名下；只有引用、没有本人正文的消息不提取人物事实。

在 **表情 → 选择与发送** 调整主动推荐比例和最短间隔。默认每轮有 50% 概率提前向聊天模型提供候选，同一会话发表情后间隔 30 秒再主动推荐；模型根据语境选图，不额外调用选图模型。设为 0% 仅按明确请求使用，100% 每轮提供候选，实际发送仍看是否合适。用户明确索要表情不受主动间隔限制。

主动复核默认全插件每小时最多一轮、每轮最多检查两条记忆，复用现有修正日志。有更新原文支持且把握足够的更正才自动执行，其余在 **记忆 → 记忆检修 → 修正历史** 查看建议与依据、确认或回滚；不会仅因记录陈旧而删除。可在记忆设置中关闭或调整间隔，模型调用计入辅助用量。

在 **自画像** 查看全部人格，选择一项填写外观描述，可上传静态 PNG、JPG 或 WebP 参考图（2 MB 以内）。普通文字对话只附上描述；处理来图且回复模型支持识图时，才附上参考图，不额外调用识图模型，也不替换 AstrBot 人格身份。
